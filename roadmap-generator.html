# Optivus — www.optivusprof.ca Fractional CMO marketing leadership website for Dean Reid. ## Files | File | URL | |------|-----| | `index.html` | www.optivusprof.ca | | `about.html` | www.optivusprof.ca/about.html | | `marketing-channel-diagnostic.html` | www.optivusprof.ca/marketing-channel-diagnostic.html | ## Assets needed in `/assets/` folder Place these files in an `assets/` subfolder on your server: - `dean-reid.png` — your headshot photo (referenced by about.html) - `og-image.png` — social share image, ideally 1200×630px - `favicon.png` — 32×32px fallback favicon (SVG favicon is already inline) ## GitHub Pages deployment 1. Create a new GitHub repository (e.g. `optivusprof`) 2. Upload all HTML files and the `assets/` folder 3. Go to Settings → Pages → Branch: main → Save 4. In your domain registrar (wherever optivusprof.ca is registered), add a CNAME record: - Type: CNAME - Name: www - Value: yourusername.github.io 5. In GitHub Pages settings, set custom domain to: www.optivusprof.ca ## Notes - All internal links use relative paths — they work locally and on any server - The Optivus logo is embedded as a base64 data URI — no external image dependency - Calendly is linked to https://calendly.com/reidexplorer
